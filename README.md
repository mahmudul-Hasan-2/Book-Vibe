# 📚 BookVibe

### README File:

#### A concise project overview.
BookVibe is a sleek, modern, and interactive web application designed for book enthusiasts to discover, review, and track their favorite reads. The platform provides a seamless user experience for managing personal reading bookshelves, exploring detailed book specifications, and engaging with a curated list of literary works. It serves as a comprehensive hub for readers to organize their digital library efficiently.

---

#### List the main technologies used.
* **Frontend Library:** React.js
* **Styling Framework:** Tailwind CSS
* **UI Components:** DaisyUI
* **Routing:** React Router DOM
* **Icons:** React Icons

---

#### Highlight the core features of the project.
* **Dynamic Bookshelves:** Easily categorize books into interactive sections like *To-Read*, *Currently Reading*, and *Completed*.
* **Comprehensive Book Details:** Dedicated routing to view in-depth information about each book, including author, genre, total pages, and publisher.
* **Interactive Data Visualization:** Custom components and charts to visually track reading progress and statistics.
* **Responsive Layout:** A fully optimized mobile-first design that works flawlessly across smartphones, tablets, and desktops.
* **Search & Filter:** Quick navigation tools to sort and find books instantly based on specific tags or ratings.

---

#### Mention the dependencies used.
* `react` & `react-dom`
* `react-router-dom` (for seamless client-side page routing)
* `recharts` / `prop-types` (for statistics and property validation)
* `react-icons` (for intuitive interface iconography)
* `tailwindcss` & `daisyui` (for rapid and modern UI styling)

#### Provide a step-by-step guide on how to run the project locally.

Follow these simple steps to set up and run BookVibe locally on your system:

**1. Clone the repository**
```bash
git clone [https://github.com/mahmudul-Hasan-2/bookvibe.git](https://github.com/mahmudul-Hasan-2/bookvibe.git)
```

**2. Navigate into the project folder**

```Bash
cd bookvibe
```

** 3. Install all required dependencies**

```Bash
npm install
```

*** 4. Start the local development server ***
```Bash
npm run dev
```

Open your browser and navigate to the local address displayed in your terminal (usually http://localhost:5173).
